Projeto de meio curso

🚀 Estrutura do Projeto:

O projeto é composto por quatro páginas principais e uma arquitetura de estilos dividida em três arquivos:

📄 Páginas (HTML):

index.html: Página inicial com as boas-vindas e introdução ao universo.
sobre.html: Detalhamento da história e cronologia (timeline) da narrativa.
jogos.html: Catálogo de todos os jogos lançados, com imagens e descrições.
livros.html: Informações sobre a expansão literária da franquia.

🎨 Estilização (CSS):

Para garantir uma organização profissional, os estilos foram separados da seguinte forma:

base.css: Estilos globais, resets, tipografia (fontes) e variáveis de cores.
layout.css: Estrutura do site (posicionamento de header, footer, menus e grids).
style.css: Detalhes internos, estilização de cards, tabelas e elementos específicos de cada página.

🛠️ Tecnologias Utilizadas:

HTML5: Uso de tags semânticas para melhor acessibilidade e SEO (<header>, <main>, <section>, <footer>).
CSS3: Layout responsivo e identidade visual personalizada com a temática da franquia.
GitHub: Versionamento e hospedagem do código.
